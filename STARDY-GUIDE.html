전체 유저플로우

로그인하지 않은 상태에서 어떤 주소로 들어와도 아래 흐름의 출발점으로 돌아옵니다. 순서대로 따라가면 모든 기능을 한 번씩 지나갑니다.

온보딩 /auth/onboarding
슬라이드 3장(자동 넘김 + 스와이프)을 보고 시작하기를 누르면 로그인으로 이동합니다. 한 번 보면 stardy.onboardingSeen이 남아서, 다음 방문부터는 로그인 화면으로 바로 갑니다.
로그인 /auth/login
카카오 / 네이버 / 구글 버튼 중 하나를 누르면 POST /auth/social-login이 호출되고 액세스 토큰이 저장됩니다. 신규 계정(isNewUser: true) → 회원가입
기존 계정 → 원래 가려던 화면(없으면 홈)
회원가입 /auth/signup
이름과 닉네임을 입력하고 중복확인을 통과해야 "입력했어요"가 활성화됩니다. 엄박봉, stardy, admin은 이미 사용 중으로 응답합니다. 중복확인 후 닉네임을 고치면 다시 비활성화됩니다.
가입 완료 /auth/signup-complete
시작할게요를 누르면 홈으로 들어갑니다. 이 시점부터 보호된 화면 전체가 열립니다.
홈 /
레벨·오늘의 학습·주간 목표 게이지, 오늘의 일정, 인기 커뮤니티, 내 스터디 그룹이 보입니다. 카드를 누르면 각 상세로 이동합니다.
커뮤니티 /community
카테고리 필터로 목록을 좁히고, 우하단 글쓰기 FAB으로 작성 화면에 들어갑니다.
글쓰기 /community/write
제목·카테고리·본문·사진을 넣고 완료를 누르면 POST /community/posts 후 방금 쓴 글의 상세 화면으로 이동합니다. 목록에도 맨 위에 남습니다.
게시글 상세 /community/:id
좋아요를 누르면 수가 오르내리고, 하단 입력창으로 댓글을 달면 목록에 바로 추가됩니다.
스터디 그룹 /studygroup
카테고리 칩으로 필터링하고, 스터디 만들기로 3단계 위저드에 들어가거나 카드를 눌러 상세로 갑니다.
스터디 생성 / 신청 /studygroup/create · /studygroup/:id/apply
생성은 완료 시 새로 만든 그룹 상세로 이동하고, 신청은 지원 동기를 넣으면 접수 완료 화면이 뜹니다.
학습관리 /study
일정 / 타이머 / 학습통계 / 목표설정 4개 탭. 일정·목표 추가와 삭제, 타이머 시작·일시정지·리셋이 모두 동작합니다.
채팅 /chat · /chat/:id
채팅방 목록에서 방을 고르면 대화가 열리고, 메시지를 보내면 말풍선이 추가되면서 목록의 마지막 메시지와 읽지 않음 수도 갱신됩니다.
내정보 /user
프로필, 바로가기 3종(북마크·참여 스터디·학습관리), 학습 게이지, 내가 쓴 게시물/댓글 메뉴, 로그아웃.
로그아웃 → /auth/login
토큰과 React Query 캐시를 모두 비우고 로그인 화면으로 돌아갑니다. 이때 다시 로그인하면 가입했던 계정으로 바로 홈에 들어갑니다.
검색은 어디서나. 헤더 돋보기를 누르면 최근 검색어 패널이 열리고, 검색어를 넣고 Enter를 치면 /community?q=검색어로 이동해 제목·본문을 검색합니다. 검색어는 최대 8개까지 기억합니다.

데모 시나리오

아래 순서대로 눌러보면 모든 기능이 한 바퀴 돕니다. 처음부터 다시 보고 싶으면 브라우저 개발자 도구에서 localStorage.clear() 후 새로고침하세요.

  1. 온보딩 — 슬라이드를 넘겨보고 "시작하기"
  2. 로그인 — "카카오 로그인" (첫 로그인이라 회원가입으로 넘어갑니다)
  3. 회원가입 — 이름 아무거나, 닉네임에 stardy를 넣고 중복확인 → 사용 중 안내 확인 → 다른 닉네임으로 바꿔 통과 → "입력했어요"
  4. 가입 완료 — "시작할게요"로 홈 진입
  5. 홈 — "공부하러 가기"를 눌러 학습관리로. 4개 탭을 돌아보고 일정을 하나 추가·삭제, 타이머 시작
  6. 커뮤니티 — 하단 탭에서 이동, 카테고리 필터를 눌러보고 우하단 연필 버튼으로 글쓰기
  7. 글쓰기 — 제목·본문을 채우고 완료 → 방금 쓴 글 상세가 열립니다
  8. 상세 — 좋아요를 눌렀다 다시 누르고, 댓글을 하나 작성
  9. 검색 — 헤더 돋보기 → "공부" 입력 후 Enter → 검색 결과 확인 → "검색 해제"
  10. 스터디그룹 — 카드를 눌러 상세 → "가입 신청하기" → 지원 동기 입력 → 접수 완료 화면
  11. 스터디 생성 — 목록으로 돌아와 만들기 → 3단계 입력 → 완료 → 새 그룹 상세
  12. 채팅 — 방에 들어가 메시지를 보내고, 목록으로 나와 마지막 메시지가 바뀐 것 확인
  13. 알림 — 헤더 종 아이콘 → 알림 하나 클릭(읽음) → "모두 읽음"
  14. 내정보 — 내가 쓴 게시물에서 하나 삭제(모달), 북마크 해제, 참여 스터디 확인
  15. 로그아웃 — 다시 로그인하면 이번엔 회원가입 없이 바로 홈으로 들어갑니다
참고 — 목 데이터의 수명. MSW 목은 메모리에 상태를 들고 있어서, 새로고침하면 글·댓글·채팅 메시지가 초기 상태로 돌아갑니다. 로그인 상태만 localStorage에 남아 유지됩니다.

인증이 도는 방식

  1. 로그인 성공 — authStore.signIn()이 토큰을 localStorage에, 사용자 정보를 스토어에 저장
  2. 모든 요청 — axios 요청 인터셉터가 Authorization: Bearer …를 자동으로 붙임
  3. 화면 진입 — ProtectedRoute가 토큰과 프로필이 모두 있는지 확인
  4. 401 응답 — 응답 인터셉터가 토큰을 지우고 스토어를 비움 → 다음 렌더에서 로그인 화면으로
  5. 로그아웃 — 토큰·스토어·React Query 캐시를 모두 정리

테스트

32개 파일 294개 테스트입니다. 모든 화면 테스트는 src/test/renderWithProviders.tsx로 React Query와 Router를 함께 감싸고, MSW로 실제 네트워크 계층을 통과시킵니다. 각 테스트가 끝나면 resetAllMocks()가 목 상태를, localStorage.clear()가 브라우저 저장소를 초기화해서 테스트끼리 간섭하지 않습니다.

남은 작업

이번 작업 범위 밖이라 손대지 않은 것들입니다.

  • 게이미피케이션 (Figma 8개 화면) — 레벨 상세, 업적, 미션 목록·상세 등 독립 섹션 전체가 미착수입니다.
  • 스터디 그룹 내부 (Figma 5개 화면) — 그룹 홈, 공지사항 목록, 그룹 내 커뮤니티가 아직 없습니다.
  • 실서버 연동 — 지금은 MSW 목이 응답합니다. 백엔드가 붙으면 src/mocks만 끄면 되도록 경로·엔벨로프를 맞춰 두었습니다.
  • 소셜 OAuth 실제 연동 — 현재는 provider만 보내는 목 로그인입니다. 실제로는 OAuth 콜백 코드를 함께 보내야 합니다.
  • 이미지 업로드 — 글쓰기의 사진은 미리보기까지만 동작하고, 업로드 API는 백엔드 확정 후 연결이 필요합니다.
